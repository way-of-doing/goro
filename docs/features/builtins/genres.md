# Genre table

The table that a genre recorded as a number refers to, in an Id3v2 `TCON` frame or an Id3v1 genre
byte: the 80 genres of Id3v1 as originally specified, and the 68 widely adopted extensions Winamp
added. See [Genres](identifiers.md#genres) and [Genre](identifiers.md#genre) for how a recorded
genre resolves to these names.

Some names are spelled as they are spelled today rather than as the original lists had them, so
that a genre one file records by number compares equal to the same genre another file records as
text: entry 67 is "Psychedelic", where the original list has "Psychadelic".
[Quirks](../../design/quirks.md) lists every name that differs. A position not in the table is one
the table assigns no genre to.
